# AI Beginner Guide 2026

> 2026 年 AI 工具入門指南集：從核心概念到實戰操作，11 篇完整指南幫助初學者快速上手主流 AI 工具。

**線上閱讀**：[Bond901.github.io/ai-beginner-guide-2026](https://Bond901.github.io/ai-beginner-guide-2026)

## 這系列指南適合誰

- 剛開始接觸 AI 工具，不確定該從哪裡開始的人
- 已經在用 ChatGPT，想了解 Claude、Gemini 等其他選擇的人
- 想搞懂 Token、Context Window 這些常見術語的人
- 想學會寫出更好的 prompt，讓 AI 輸出更精準的人

不需要程式背景，每篇都從零開始講起。

每篇指南都支援：**匯出 PDF**（透過瀏覽器列印另存）、**開啟 NotebookLM** 與**複製連結**，方便存檔、加入自己的筆記本或分享。全站支援**站內搜尋**；每篇標示**最後更新／驗證日期**，超過半年未驗證會提示內容可能已變動。

## 怎麼開始（依程度／目的）

- **完全新手** → 先讀「基礎觀念」（LLM 核心概念 → Prompt 演進 → 個人化設定）建立底層理解
- **想用某個平台** → 直接挑「平台工具」（Claude / OpenAI / Gemini）
- **想做 agent／自動化** → 進「進階 · Agent」（擴充機制 / Code Skills / Opus 4.8）
- **想做檢索／應用** → 看「流程 · 應用」（RAG → SDLC）

每篇都可獨立閱讀，不一定要按順序。
