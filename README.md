# AI Beginner Guide 2026

> 2026 年 AI 工具入門指南集：從核心概念到實戰操作，11 篇完整指南幫助初學者快速上手主流 AI 工具。

**線上閱讀**：[Bond901.github.io/ai-beginner-guide-2026](https://Bond901.github.io/ai-beginner-guide-2026)

## 這系列指南適合誰

- 剛開始接觸 AI 工具，不確定該從哪裡開始的人
- 已經在用 ChatGPT，想了解 Claude、Gemini 等其他選擇的人
- 想搞懂 Token、Context Window 這些常見術語的人
- 想學會寫出更好的 prompt，讓 AI 輸出更精準的人

不需要程式背景，每篇都從零開始講起。

每篇指南都支援：**匯出 PDF**（透過瀏覽器列印另存）、**開啟 NotebookLM** 與**複製連結**，方便存檔、加入自己的筆記本或分享。

## 推薦閱讀順序

1. **LLM 核心概念** — 先建立底層理解，後面讀工具指南會輕鬆很多
2. **Prompt Engineering 演進** — 掌握與 AI 溝通的方法論
3. **AI 個人化設定精煉** — 學會客製化你的 AI 工具
4. 挑選一個你想用的平台，閱讀對應的工具指南 → [Claude](guides/claude-desktop-guide.html) · [OpenAI](guides/openai-tools-guide.html) · [Gemini](guides/gemini-tools-guide.html)
5. **Claude Opus 4.8 技術指南** — 想深入 Anthropic 旗艦模型的功能與 API 實務時閱讀
6. **AI Agent 擴充機制** — 理解 Skill / MCP / Plugin 三層架構
7. **Claude Code Skills 技術指南** — 動手把重複流程封裝成 skill
8. **RAG 檢索增強生成 完整指南** — 讓 AI 參照外部知識回答的系統工程
9. **AI 時代軟體開發流程** — 了解 AI 如何改變開發全流程

每篇也可以獨立閱讀，不一定要按順序。
