一眼看懂三種模式

很多人只知道在瀏覽器用 Claude 聊天，其實 Claude Desktop 提供三種根本不同的工作方式。每種模式設計給不同的工作情境，不是「升級版」的關係，而是並列的三條路徑。

💬

CHAT

對話助手。問問題、寫作、分析、腦力激盪。你輸入，它回答。和瀏覽器版完全一樣。

🗂️

COWORK

自主代理人。指派任務後讓 Claude 去執行，可讀寫本機檔案、串接 Google Drive / Slack / Gmail。不需要技術背景。

⌨️

CODE

工程師的 AI 協作者。在 Terminal 或 IDE 裡運行，理解整個 codebase，自動改檔案、跑測試、送 PR。

💡

一句話記憶法：Chat 是你問它答、Cowork 是你指派它執行、Code 是你協作一起寫程式。

// 02

Chat 模式

Chat 是最多人熟悉的入口，也是理解 Claude 能力的起點。無論在瀏覽器、手機 App、還是 Desktop App，功能完全相同。

💬

Claude Chat — 對話助手

CONVERSATION MODE
能做什麼
問答、文章撰寫、翻譯、摘要、分析文件、腦力激盪、草擬 Email、解釋概念、程式片段說明
在哪裡用
瀏覽器 claude.ai、手機 App（iOS / Android）、Claude Desktop App（Chat 分頁）
需要什麼
免費帳號即可使用（有每日限制），付費方案（Pro $20/月）取得更高配額
侷限
關閉視窗後對話記憶消失（Projects 功能可儲存記憶）；不能主動操作你電腦的檔案

📖 實際使用情境

  • 「幫我把這封英文 Email 翻成中文，語氣要正式」
  • 「解釋一下機器學習中的 overfitting 是什麼意思」
  • 「草擬一份會議紀錄，重點如下：…」
  • 「分析這段文字的論述邏輯，指出其中的漏洞」

Step-by-step：Chat 第一次使用

01

前往 claude.ai

直接在瀏覽器開啟 claude.ai，或下載 Claude Desktop App（claude.com/download）。點選左上角「New chat」。

02

輸入你的問題或任務

在底部輸入框直接打中文就好。盡量具體描述：背景 + 你要的結果 + 格式需求，越清楚回答越精準。

03

多輪對話迭代

回答不夠好？繼續說「太冗長，精簡到 200 字」或「改成更正式的語氣」。Chat 記得這輪的對話，可以持續修改。

04

使用 Projects 儲存記憶

左側欄建立「Project」，上傳參考文件並寫入說明。之後的對話 Claude 會記住這個 Project 的背景，不用每次重新解釋。

// 03

Cowork 模式

Cowork 是 Anthropic 在 2026 年 1 月推出的新功能，定位是「知識工作的自主代理人」。它和 Chat 最大的差異是：你不用坐在電腦前盯著它，你指派任務，它自己去執行。

🗂️

Claude Cowork — 知識工作代理人

AUTONOMOUS AGENT MODE
能做什麼
讀寫本機資料夾的檔案；連接 Google Drive、Gmail、Slack 等服務；執行多步驟任務（例：讀 40 份 PDF → 整理成 Excel 分析表）；排程重複性任務
在哪裡用
只在 Claude Desktop App（macOS / Windows）。Pro 和 Max 使用者可用手機下達指令，電腦端執行。
需要什麼
付費方案（Pro、Max、Team、Enterprise 均可）+ Claude Desktop App
適合誰
研究員、分析師、律師、財務人員、營運人員——任何處理大量文件、重複性任務、但不需要寫程式的知識工作者

📖 實際使用情境

  • 「這個資料夾有 40 份供應商報價 PDF，幫我彙整成一張比較 Excel 表，包含品項、單價、交期」
  • 「讀我 Gmail 最近 50 封信，找出所有需要我回覆的 action item 列成清單」
  • 「把 Slack #general 頻道本週的重點摘要成一份週報，存成 Word 檔」
  • 「分析我 Google Drive 的財報資料夾，找出過去三季的收入趨勢」
⚠️

安全提醒：Cowork 有桌面控制能力（可操作鍵盤滑鼠），Anthropic 建議不要在含有敏感資料的應用程式旁使用，並隨時確認它的執行步驟。

Step-by-step：Cowork 第一次使用

01

下載並安裝 Claude Desktop

前往 claude.com/download，下載 macOS 或 Windows 版。安裝後登入你的付費帳號。

02

切換到 Cowork 分頁

開啟 Desktop App，點選左側「Cowork」分頁（或頂部導航切換）。

03

連接你需要的服務

點選「Connectors」，授權連接 Google Drive / Gmail / Slack 等。也可以直接指定本機資料夾路徑讓 Cowork 存取。

04

下達具體任務

描述你要的結果，而不是步驟。例如：「分析 /Downloads/reports 資料夾的所有 PDF，輸出一份 summary.md」。

05

審查執行步驟

Cowork 會顯示每個動作（讀哪個檔案、寫什麼）。確認沒問題後按「繼續」，它會自動完成剩餘步驟。

// 04

Code 模式

Claude Code 是給工程師和想學程式的人設計的。它不只是「幫你寫程式碼片段」的 AI，而是能理解你整個專案結構、跨多個檔案同時修改、自動跑測試的編程代理人。

⌨️

Claude Code — 工程師 AI 協作者

AGENTIC CODING MODE
能做什麼
理解整個 codebase 架構；跨多檔案修改；執行 shell 命令；跑測試並修 bug；管理 Git（commit、PR）；和 VS Code / JetBrains IDE 整合
入口方式
① Terminal CLI（輸入 claude）② Claude Desktop App 的 Code 分頁 ③ VS Code / JetBrains 擴充套件
需要什麼
付費方案（Pro $20/月以上）+ macOS / Linux / Windows 10+。Desktop App 不支援 Linux（Linux 用 CLI）。
適合誰
軟體工程師、想學程式的人、獨立開發者、技術創業者

📖 實際使用情境

  • 「在這個 signup form 加入 email 格式驗證，修改相關測試」
  • 「分析整個專案架構，找出效能瓶頸並提出改善方案」
  • 「把這個 Python 2 專案遷移到 Python 3，保留所有功能」
  • 「幫我寫一個 CLAUDE.md，記錄這個專案的 coding convention」

Step-by-step：Claude Code CLI 第一次使用

01

確認系統需求

需要 macOS / Linux / Windows 10+，以及 Terminal（macOS 用內建 Terminal；Windows 用 PowerShell，不要用 Git Bash）。

02

安裝 Claude Code CLI

在 Terminal 執行以下指令：

# macOS / Linux curl -fsSL https://claude.ai/install.sh | sh # 或用 Homebrew（macOS） brew install claude-code # Windows PowerShell winget install Anthropic.ClaudeCode
03

登入帳號

執行 claude，第一次會開啟瀏覽器進行授權登入。完成後回到 Terminal 即可使用。

04

進入你的專案目錄

切換到你的程式碼資料夾，執行 claude 啟動互動模式。

cd ~/my-project claude # 啟動後輸入你的任務，例如： # > 分析這個專案的架構，告訴我主要的模組有哪些
05

善用 Plan Mode（重要！）

複雜任務前先輸入「先制定計畫，不要修改任何檔案」，讓 Claude 分析並展示方案，確認後再執行。這能大幅降低出錯風險。

06

建立 CLAUDE.md（強烈建議）

在專案根目錄建立 CLAUDE.md 檔案，寫入 coding 規範、技術棧、測試要求。Claude Code 每次啟動都會自動讀取，確保一致性。

# CLAUDE.md 範例 ## Tech Stack - Backend: Python 3.12 + FastAPI - Frontend: React 18 + TypeScript - DB: PostgreSQL + SQLAlchemy ## Coding Rules - All functions must have type hints - Tests required for all new features (pytest) - No direct SQL queries, use ORM only

我該選哪一個？

🌲 決策樹：根據情境選擇模式

我只是想問問題、寫文章、分析一段文字
→
Chat
我有一批文件要處理，懶得自己做
→
Cowork
我要串接 Gmail / Google Drive 自動化
→
Cowork
我要寫程式 / 修 bug / 跑測試
→
Code
我是工程師，想讓 AI 幫我管整個 repo
→
Code
我沒有技術背景，但想要自動化複雜任務
→
Cowork
我剛開始使用 Claude，想先試試看
→
Chat（免費）
🔑

三種模式不互斥。很多人的日常是：用 Chat 腦力激盪 → Cowork 整理研究資料 → Code 實作功能。買一個 Pro 訂閱，三種都能用。

// 08

立刻開始：5 分鐘上手路徑

根據你的身份，選擇最適合的入門路徑：

PATH A — 完全新手
  1. 前往 claude.ai，免費建立帳號
  2. 開一個 New Chat，用中文問任何問題（例：「幫我解釋量子電腦是什麼」）
  3. 試試上傳 PDF / 圖片讓 Claude 分析
  4. 熟悉後，建立一個 Project，上傳你的工作資料當背景知識
PATH B — 非技術工作者想要自動化
  1. 下載 Claude Desktop（claude.com/download），升級 Pro
  2. 切換到 Cowork 分頁
  3. 先試一個簡單任務：「讀桌面上的 report.pdf，列出其中的三個主要結論，存成 summary.txt」
  4. 成功後，嘗試連接 Google Drive，指派更複雜的任務
PATH C — 工程師 / 想學程式的人
  1. 升級 Pro，安裝 CLI：curl -fsSL https://claude.ai/install.sh | sh
  2. 進入一個現有的小專案目錄，執行 claude
  3. 第一個任務：「描述這個專案的架構，不要修改任何檔案」（先觀察）
  4. 建立 CLAUDE.md，寫入你的 coding 規範
  5. 嘗試要求它修復一個小 bug，觀察它的 Plan → Execute 流程
🎯

給所有新手的通用建議：第一次使用時，給越具體的任務，效果越好。不要說「幫我整理資料」，而是說「讀 /Downloads/sales_2026Q1.xlsx，找出銷售額前三名的產品，存成 top3.md」。清晰的輸入 = 精準的輸出。
