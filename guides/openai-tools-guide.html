一眼看懂三種工具

OpenAI 的三個工具定位截然不同，不是「升級版」的關係，而是針對不同場景設計的三條路徑。選對工具，事半功倍。

💬

CHATGPT

對話式 AI 助理。問答、寫作、分析、資料摘要、圖片理解、語音對話。不需要技術背景。

🤖

CODEX

軟體開發 AI 代理人。讀懂整個 codebase、寫程式、修 bug、重構、跑測試、送 PR。給工程師。

⌨️

CODEX CLI

Terminal 中的 Codex。在本機專案資料夾直接讓 AI 讀檔、改檔、執行命令。需熟悉命令列。

💡

一句話記憶法：ChatGPT 是問答與寫作、Codex 是軟體開發代理、Codex CLI 是把 Codex 搬進 Terminal。三者不互斥，可以搭配使用。

// 02

ChatGPT

ChatGPT 是最多人熟悉的入口——在瀏覽器直接輸入問題，不需安裝、不需技術背景。但它的能力遠不只「聊天」，上傳文件、分析試算表、語音對話、Canvas 協作寫作都是內建功能。

💬

ChatGPT — 對話式 AI 助理

CONVERSATIONAL AI
能做什麼
問答、解釋概念、寫作草稿、摘要文件、翻譯、資料分析（CSV / Excel）、圖片理解與生成、語音對話、Canvas 協作、Projects 長期記憶
使用介面
網頁（chatgpt.com）、iOS / Android App、桌面 App（macOS / Windows）
需要什麼
免費可試用（不登入僅保留當次對話）；登入後可儲存紀錄；付費方案（Plus、Pro、Business）解鎖更高配額與功能
適合誰
一般使用者、學生、知識工作者、開發者——任何需要文字、圖片、資料分析的人
注意事項
可能產生幻覺（Hallucination）；重要決策需交叉查證；避免輸入敏感資料

📋 八大核心功能一覽

  • 文字對話：問答、概念解釋、文字改寫、草稿撰寫
  • 圖片輸入 / 生成：分析截圖、圖表、上傳圖片，或生成圖片
  • 文件上傳：PDF、簡報、純文字——摘要、擷取資訊、問答
  • Data Analysis：分析 CSV / Excel，支援趨勢摘要、資料清理與視覺化
  • Voice Mode（語音）：以自然語音對話並接收語音回應
  • Canvas：共同寫作、編輯、debug 的共享協作空間
  • Projects：把聊天、檔案與上下文整理在長期目標下
  • Custom GPTs：建立具特定指示、知識與工具的專用助理
⚠️

重要提醒：ChatGPT 可能產生不正確或編造的內容。涉及重要決策、醫療、法律、財務的資訊，務必自行查證原始來源。

Step-by-step：ChatGPT 第一次使用

01

前往 chatgpt.com

不登入也可以試用，但對話不會被儲存。要保存紀錄、使用個人化設定，需登入或建立帳號。

02

選擇輸入方式

純文字直接打；要分析文件點附件圖示上傳 PDF / Excel；要用語音點麥克風圖示；要協作編輯點 Canvas。

03

用結構化 Prompt 提問

越具體，回答越精準。參考下方「初學者 Prompt 格式」，填入角色、目標、背景與格式需求。

04

多輪對話迭代

回答不夠好？繼續說「太冗長，精簡到 150 字」或「改成條列式」。ChatGPT 記得本輪對話，持續修改即可。

05

建立 Project 保存背景知識

左側欄建立「Project」，上傳參考文件並寫入說明。之後所有對話 ChatGPT 都記得這個 Project 的背景。

🎯 初學者建議 Prompt 格式

請扮演 [角色]。 我的目標是：[任務目標]。 背景資料：[必要上下文]。 限制條件：[字數、格式、語氣、語言]。 請用 [表格／步驟／清單／摘要] 輸出。

範例：

請扮演技術文件編輯。 我的目標是讓非工程背景讀者理解 API 是什麼。 請用繁體中文、條列式、附 3 個生活化比喻。 避免過度技術細節。
// 03

Codex

Codex 是 OpenAI 針對軟體開發設計的 AI coding agent（程式代理）。它不只是建議程式碼片段，而是能理解整個 codebase 架構、自主執行多步驟開發任務的代理人。ChatGPT Plus、Pro、Business、Edu、Enterprise 方案均包含 Codex。

🤖

Codex — 軟體開發 AI 代理人

CODING AGENT
能做什麼
依需求產生程式碼；理解陌生或 legacy codebase；review 程式碼；追蹤故障原因與提出修復；自動化重構、測試、migration 與環境設定
使用入口
Codex App（桌面 GUI）、IDE Extension（VS Code / Cursor / Windsurf）、Codex CLI（Terminal）、Codex Cloud（瀏覽器 + GitHub 整合）
使用介面
Codex App 支援 macOS / Windows；以 ChatGPT 帳號或 OpenAI API Key 登入
適合誰
開發者、工程團隊、技術 PM——需要 AI 協助軟體開發流程的人
方案需求
ChatGPT Plus、Pro、Business、Edu、Enterprise 包含 Codex

📖 六類常見任務與對應指令

任務 可輸入的自然語言指令
理解專案請說明這個專案的架構與主要模組。
找 bug請找出登入流程可能失敗的原因，並提出最小修改。
寫功能請新增使用者設定頁面，遵循現有程式碼風格。
重構請把重複邏輯抽成共用函式，不改變既有行為。
補測試請為這個函式補上單元測試，涵蓋成功與錯誤情境。
Code Review請 review 最近修改，指出邏輯錯誤與未處理的 edge case。
🔑

三條安全習慣：① 先讓 Codex 解釋計畫，再允許修改；② 每次任務範圍要小，不要一次重寫整個系統；③ 所有修改都要人工 review 與測試，Codex 不能取代工程審查。

Step-by-step：Codex App 第一次使用

01

下載 Codex App

從 OpenAI 官方頁面下載 macOS 或 Windows 版 Codex App，以 ChatGPT 帳號或 OpenAI API Key 登入。

02

選擇專案資料夾

開啟 App 後選擇本機的專案目錄（資料夾），Codex 會讀取其中的程式碼結構。

03

先下達「讀懂」指令，不要直接修改

第一個任務建議是：「請說明這個專案的架構與主要模組，不要修改任何檔案。」確認 Codex 理解正確後再進行下一步。

04

先建立 Git checkpoint 再修改

在 Codex 修改程式碼前，確認有 Git commit 作為安全網，方便回復 Codex 造成的非預期變更。

05

下達小範圍任務，人工審查 diff

提出具體、小範圍的任務，Codex 執行後人工 review 每個變更，確認無誤後再 commit。

// 04

Codex CLI

Codex CLI 是把 Codex 放進 Terminal 的命令列工具，open source（開源），以 Rust 建置。它能在你選定的本機目錄中讀取、修改並執行程式碼，並提供全螢幕 Terminal UI 讓你即時審查每個動作。

⌨️

Codex CLI — Terminal 中的 Codex

CLI AGENT
能做什麼
讀取 / 修改 / 執行本機目錄中的程式碼；全螢幕 Terminal UI；即時顯示計畫、diff 與執行命令；可繼續先前 session
安裝方式
npm 或 Homebrew 安裝；open source，以 Rust 建置
支援平台
macOS、Linux、Windows（PowerShell 原生；需 Linux-native 環境時用 WSL2）
需要什麼
ChatGPT 帳號或 OpenAI API Key；基本命令列操作能力
適合誰
熟悉 Terminal 的開發者，希望在命令列中直接讓 AI 操作本機專案
⚠️

高風險旗標警告：官方文件列出 --dangerously-bypass-approvals-and-sandbox 旗標，說明只應在外部已強化的環境中使用。初學者絕對不要使用此旗標。

Step-by-step：Codex CLI 第一次使用

01

安裝 Codex CLI

選擇以下任一方式安裝：

# 方式 A：npm 安裝 npm install -g @openai/codex # 方式 B：Homebrew 安裝（macOS） brew install codex
02

建立 Git Checkpoint

進入專案資料夾後，先建立一個乾淨的 Git commit 作為安全網。

cd path/to/your/project git status git add . git commit -m "checkpoint before codex task"
03

啟動 Codex CLI

在專案目錄執行 codex，第一次會要求以 ChatGPT 帳號或 API Key 登入。

codex # 或直接帶入第一個任務 codex "請先閱讀這個專案，說明架構與主要模組。不要修改任何檔案。"
04

先讀懂，再修改

啟動後先要求 Codex 說明專案，確認理解正確後再提出小範圍修改任務，並在 Terminal UI 中即時審查每個動作。

05

繼續先前 Session

下次回到同一專案，可以用 codex resume --last 恢復上次的對話，不需要重新說明背景。

⌨️ 常用命令速查

# 啟動互動模式 codex # 啟動並帶入初始任務 codex "Explain this codebase to me" # 恢復最近一次 session codex resume --last # 查看所有可恢復的 session codex resume --all # 指定工作目錄 codex --cd path/to/project # 指定使用的模型 codex --model model_name # 控制何時需人工批准（預設為每次都問） codex --ask-for-approval on-request # 附加圖片作為初始 prompt codex --image path/to/image.png

我該選哪一個？

🌿 決策樹：根據情境選擇工具

想學概念、整理文件、撰寫文字
→
ChatGPT
想快速問一段程式碼的意思
→
ChatGPT（片段）或 Codex（整個 repo）
想理解整個專案或修改程式碼
→
Codex
平常用 VS Code / Cursor，想要 AI 嵌入 IDE
→
Codex IDE Extension
想讓 AI 在 Terminal 直接改檔、跑命令
→
Codex CLI
不熟 Terminal，但想用 Codex
→
Codex App（GUI 介面）
剛開始使用 AI 工具，想先體驗
→
ChatGPT（免費可試用）
🔗

官方建議學習順序：先學 ChatGPT（熟悉 Prompt、文件上傳）→ 再學 Codex 基本概念（codebase、Git、diff）→ 選入口（不熟 terminal 用 App / IDE；熟 terminal 用 CLI）→ 最後建立固定工作流。

// 07

立刻開始：上手路徑

PATH A — 完全新手 / 知識工作者
  1. 前往 chatgpt.com，不登入先試用，熟悉對話感覺
  2. 試著用結構化 Prompt：「請扮演 X，我的目標是 Y，請用條列式輸出」
  3. 上傳一份 PDF 或試算表，問「這份文件的主要結論是什麼？」
  4. 建立帳號後，建立一個 Project，把常用的背景知識存進去
  5. 熟悉後，試試 Custom GPT：建立一個固定格式的週報助手
PATH B — 開發者 / 不熟 Terminal
  1. 確認有 ChatGPT Plus 以上方案（包含 Codex）
  2. 下載 Codex App（macOS / Windows），以 ChatGPT 帳號登入
  3. 選擇一個有 Git 的小型專案資料夾
  4. 第一個任務：「請說明這個專案的架構，不要修改任何檔案」
  5. 確認理解後，嘗試讓它修一個小 bug，人工審查 diff 後 commit
PATH C — 工程師 / 熟悉 Terminal
  1. 安裝：npm install -g @openai/codex 或 brew install codex
  2. 進入 Git 專案，先建立 checkpoint：git commit -m "before codex"
  3. 執行 codex，第一次登入後輸入：「請閱讀此專案架構，不要修改任何檔案」
  4. 觀察 Codex 的計畫與 diff，熟悉 Terminal UI 的審查流程
  5. 嘗試 codex resume --last，體驗 Session 恢復功能
🎯

給所有新手的通用建議：第一個任務永遠選「讀懂，不修改」——讓 AI 先說明它的理解，確認正確後再允許修改。這個習慣能大幅降低因 AI 誤解導致的非預期變更。
